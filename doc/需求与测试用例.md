# 需求与测试用例

版本 0.1.0；状态：已确认，2026-10-20。用户明确选择单个数字输入 → 单个数字输出。交付原生 TurboWarp/Scratch `.sb3`，不开发专用 MCP Bridge，不发布到外部平台。

三枚按钮：重置、训练、测试。重置清空本轮样本、训练记录与预测值，初始化网络；训练依次询问输入数字和目标输出，保留已提交样本，并学习当前全部样本；测试只询问输入，计算并显示预测结果，不修改权重、样本或训练轮次。相同输入再次训练时更新该样本目标；最多 32 个不同输入，达到上限时提示并保持现有模型。

数值支持 -1000～1000 的十进制、负数和小数；空白、非数字、Infinity、超范围均拒绝。首版用于演示近似学习，测试值远离训练范围时不保证预测准确。不预装训练样本。无样本时测试提示先训练。输入过程中其他按钮禁用，防止多个问题和训练互相覆盖；可使用 1/2/3 快捷键对应三个按钮。

| 用例 | 验收条件 |
| --- | --- |
| U01 | 绿旗出现三个按钮和网络示意；未训练、样本数 0、无预测值 |
| U02 | 点击训练，顺序输入 x 和 y；只在两项合法后提交 |
| U03 | 训练 0→0、1→2、2→4 后，训练样本误差下降，测试 1.5 接近 3（误差 <0.35） |
| U04 | 实际多层网络前向与反向传播，训练会修改权重；不是查表返回 |
| U05 | 测试不会修改权重、样本或训练轮次；重复测试结果一致 |
| U06 | 重置后样本、轮次和预测清空，权重回到初始值；可学习相反规则 |
| U07 | 非法/空/越界输入后样本和权重不变，有清晰提示 |
| U08 | 相同输入更新目标而不增加样本数，保留其他样本 |
| U09 | 输入期间重复点按钮不叠加问题、不破坏状态；完成后恢复按钮 |
| U10 | 32 个样本上限生效；达到上限仍能更新已有输入 |
| U11 | 保存 SB3 后加载，三个按钮与训练/测试仍可用 |
| U12 | 桌面和窄屏全舞台可阅读、按钮不重叠；保存运行截图和 VM 断言 |
