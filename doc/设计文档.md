# 设计文档

版本 0.1.0；状态：待实现。

采用 Scratch 原生积木实现 1–6–1 多层感知机，隐藏层 tanh、输出层线性、均方误差、随机梯度下降（固定样本顺序）。不使用云端模型或额外扩展。标准反向传播的有限教育实现用原生积木表达，以便用户打开项目检查；Node 参考模型只用于数值校验，不代替作品运行时。

每次加入/更新样本后，用当前完整样本重新训练 600 轮，防止只记住最后一个样本。输入、目标分别除以 max(1, 样本绝对值最大值) 缩放，输出还原原单位。初始化采用固定、非对称的小权重，避免对称神经元并使复现稳定；重置不代表随机更换数据。

全局变量：状态、忙碌、样本数、训练轮次、均方误差、测试输入、预测输出、最近样本。隐藏列表保存样本和权重 W1/B1/W2/H，输出偏置 B2。控制器管理问答、校验、提交和训练；三枚精灵按钮通过广播请求行为，不直接操作权重。

控制器用自定义“前向计算”“训练一批”积木；每批 25 轮使用 warp，批间 wait 0 保持浏览器可响应。tanh 用 (e^(2z)-1)/(e^(2z)+1)，将 z 限制在 [-10,10]，防止指数溢出。反向传播先使用旧 W2 计算隐藏层梯度，再更新 W2。预测四舍五入至 4 位小数，仅用于显示；内部训练用完整精度。

舞台 480×360：浅色背景、1–6–1 图示、预测卡片、样本/轮次/误差指标与状态栏，底部三个大按钮。Scratch 询问输入使用原生 ask/answer。固定舞台比例由 TurboWarp 全舞台模式缩放到窄屏；不引入额外网页。

模块：src/network.mjs 参考算法；src/scratch-builder.mjs 积木序列化；src/build-project.mjs 作品与界面生成；tests/*.test.mjs 数值、结构和边界测试。真实交互通过现有官方 Playwright MCP 完成，验证 VM 数据和实际点击/输入，并保存证据。
