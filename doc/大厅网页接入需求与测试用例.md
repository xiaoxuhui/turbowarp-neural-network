# 神经网络实验室：大厅网页接入需求与测试用例

2026-10-26 用户授权实施。复用现有 SB3 和原生积木，不重新实现神经网络，不制作独立 APK，Bridge 保留为开发工具。

- 保持 1–6–1 网络、三按钮、数值范围、样本上限和训练算法；网页提供本地运行时、触摸输入及自动存档。
- 原有 SB3、训练成果及编辑器工作流保留；网页输出到独立 web-dist/，运行不依赖 TurboWarp 网站。
- 首次打开保留所选 SB3 的初始状态；后续打开恢复最后一个完整且空闲的训练状态。中断输入/训练不覆盖上一份完整存档。
- 存档使用 turbowarp-neural-network. 前缀、版本和来源身份；损坏或不兼容存档保留原字节并明确提示，不清空其它游戏数据。
- 源码仓库现已公开；自有代码采用 MIT 许可，第三方运行时保留原许可。大厅仍仅发行运行资源，按固定提交打包、签名和匿名核验。
