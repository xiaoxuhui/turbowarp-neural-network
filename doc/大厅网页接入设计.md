# 大厅网页接入设计

状态：设计；2026-10-26。

精确固定官方 @turbowarp/packager 版本，把已有 dist/neural-network.sb3 连同运行时输出为离线 HTML。算法和三枚角色按钮继续在 Scratch VM 内执行；web/ 中的适配只负责浏览器生命周期、布局、输入和持久化。

只保存空闲时完整的舞台变量与列表；数据以稳定变量 ID 和版本化合同校验。启动先运行原初始化流程，再恢复完整状态，避免绿旗初始化覆盖保存的训练成果。空闲状态变化后自动存档，训练/问答中保留上一个稳定快照；存储失败向用户报告。恢复失败保留坏存档并提供显式重新开始入口。

网页产物独立放 web-dist/，携带 LICENSE、第三方声明、构建来源及资源摘要。构建必须可重复，原 SB3 SHA 不变；已有结构测试改为内存构建，防止测试覆盖用户训练成果。共享的技术路径在神经网络先验证，再移植到逻辑小实验室。

大厅作为宿主已有动态游戏协议；用 turbowarp-neural-network ID 和对应动态存档合同接入。资源打包遵循现有安全扫描和签名流程，不放宽存储/缓存约束，不打包开发工具、凭据、截图或测试会话。
